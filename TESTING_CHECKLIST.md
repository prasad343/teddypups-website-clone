# Technical assignment — manual testing checklist

Complete this checklist with your own real test results before claiming a complete submission.

## Desktop pages
- [ ] Home page looks close to reference at ~1440px wide.
- [ ] Puppies grid, all required data and card links work.
- [ ] Individual puppy pages open for at least 5 records.
- [ ] Gallery next, previous and thumbnails change photos.
- [ ] Happy families images, headings and captions look right.
- [ ] How it works local/imported tabs switch correctly.
- [ ] FAQ search filters questions correctly.
- [ ] FAQ accordion opens and closes.
- [ ] Contact and puppy enquiry forms show validation errors.
- [ ] All header and footer links lead somewhere valid.
- [ ] 404 page appears for unknown URLs.

## Mobile pages
- [ ] Test at Chrome DevTools widths: 390px, 768px and 1280px.
- [ ] Mobile menu opens and closes.
- [ ] No horizontal scrolling or off-screen buttons.
- [ ] Hero and puppy cards look good.
- [ ] Contact form remains readable, with no tiny text.
- [ ] WhatsApp and other buttons are not covered by overlays.

## Functionality and honesty
- [ ] Decide and implement real enquiry submission if required. The starter only opens an email client.
- [ ] No broken image URLs or wrong puppy breed photos.
- [ ] No unauthorized copied assets.
- [ ] No browser console errors.
- [ ] All images have meaningful alt text.
- [ ] No API keys, credentials, or secrets in GitHub repository.
- [ ] All content and links have been checked against the live reference.

## Deployment and submission
- [ ] `npm run build` finishes successfully.
- [ ] GitHub repository contains source code, README, and appropriate commits.
- [ ] Vercel/Netlify link loads in an incognito window.
- [ ] Deep links load directly after a browser refresh.
- [ ] Loom covers tools, AI prompts, code, design decisions, challenges, testing, deployment.
- [ ] Loom link opens without requesting permission.
- [ ] Email has exactly three URLs and correct required subject, To and Cc.
